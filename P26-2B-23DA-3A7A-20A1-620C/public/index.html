Jogo da Memória Temático

Projete um jogo de memória baseado em pares de cartas que exigem correspondência visual ou conceitual (ex: código e sua saída). A interface deve empregar transformações CSS 3D acionadas via JavaScript vanilla para o efeito de virar as cartas, mantendo o cabeçalho com os dados do usuário obtidos via login do Discord. A disposição das cartas é embaralhada no servidor Cloudflare no início da sessão, enviando apenas identificadores opacos para o frontend. Quando o jogador seleciona duas cartas, uma requisição consulta o backend para verificar se os identificadores formam um par válido, incrementando o contador de movimentos no banco D1 e registrando a eficiência do jogador ao descobrir todos os pares.
